# Flight Itinerary Scorer

A Streamlit web app that compares flight itineraries based on:

- Ticket price
- Number of stops
- Total travel time
- Connection time
- Traveler preference

## Features

- Compare 2–6 flights
- Rank flights from best to worst
- Choose a preference:
  - Balanced
  - Cheapest
  - Shortest Travel Time
  - Fewest Stops
- Get a recommended flight
- See a score and rating for each itinerary

## Built With

- Python
- Streamlit

## Run Locally

```bash
streamlit run flight_app.py
