# Flight Itinerary Scorer 

A Python web application that compares flight itineraries and recommends the best option based on a traveler's preferences.

## Live Demo

https://flight-itinerary-scorer-6shvwitzyfganggeeqt6hf.streamlit.app/

## Features

- Compare multiple flight itineraries
- Score flights from 0–100
- Rank flights automatically
- Consider price, stops, travel time, and layover time
- Choose between:
  - Balanced
  - Cheapest
  - Shortest Travel Time
  - Fewest Stops
- Receive a personalized flight recommendation

## Technologies

- Python
- Streamlit
- GitHub
